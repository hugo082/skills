# Shelf

Reading-list app: a JSON API and one HTML page, Node only, no dependencies.

- `npm run check` is the full check (lint + tests). CI runs it on every PR.
- `npm start` serves the app on http://localhost:4173 (`PORT` overrides it).
- Issues live in `docs/issues/SHELF-<n>.md`.
- Branches: `<type>/SHELF-<n>-<slug>`. Commits: Conventional Commits.
