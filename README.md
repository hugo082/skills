# skills

![Skills](https://img.shields.io/badge/Skills-2-8B5CF6)

This repository is my personal [skills.sh](https://skills.sh/) style knowledge base: a place to document practical, reusable skills I can apply across projects.

## Installation

```bash
npx skills add https://github.com/hugo082/skills
# Or
npx skills add https://github.com/hugo082/skills --skill domain-driven-design
npx skills add https://github.com/hugo082/skills --skill domain-driven-design-for-typescript
```

## Skills index

- [`domain-driven-design`](./domain-driven-design/) — foundations and practical patterns for applying DDD in real systems.
- [`domain-driven-design-for-typescript`](./domain-driven-design-for-typescript/) — opinionated, functional-first DDD implementation structure for modern TypeScript (ESM), dependency-agnostic, and class-free.
